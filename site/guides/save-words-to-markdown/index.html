How to save translated words to Markdown

A repeatable Arabic ↔ English workflow for people who want a word bank they own — in Obsidian, Logseq, VS Code, or any text editor.

Updated November 4, 2026 7 min read Works with any Markdown editor

If you translate words while reading or watching videos, the translation usually disappears when you close the tab. This guide shows how to keep each word and translation in Hassala's private local word bank, then export a Markdown file whenever you want and open it in the notes app you already use.

What you need

  • Chrome, Brave, Edge, or Chromium on Linux, macOS, or Windows.
  • Hassala from GitHub Releases. The Chrome Web Store release is still being prepared.
  • No Python, native host, account, or file-system permission.
  • A Markdown editor such as Obsidian, Logseq, Typora, or VS Code — optional, but useful.

Step 1 — Install Hassala

  1. Download hassala-2.0.4-testers.zip from Releases and extract it to a stable folder.
  2. Open chrome://extensions, brave://extensions, or edge://extensions.
  3. Enable Developer mode and click Load unpacked.
  4. Select the folder that contains manifest.json.
  5. Pin Hassala to the toolbar if you want one-click access.
Nothing else to install. Words are stored inside the extension, not in a file on your device. There is no native host, no Python dependency, and no automatic file writing.

Step 2 — Create a folder

Open Hassala Settings and find Save new words to. Create a folder for the words you are collecting, for example English, Arabic, or Programming.

These folders live inside the extension. They are an organising tool, not directories on your hard drive. You can rename them, move words between them, and delete a folder without deleting its words — those move back to General.

Step 3 — Translate a word

There are three ways to open the translator:

  • Click the Hassala icon in the toolbar.
  • Click the floating button on any page.
  • Select text on a page and click Translate next to it.

Type an English or Arabic word. Hassala detects the direction and starts translating after a short pause, or immediately when you press Enter.

Step 4 — Save the word locally

When the translation looks right, click Add to Hassala. The word pair is stored in the folder selected under Save new words to, and the input clears for the next word.

  • If the pair already exists, you see Already in your word bank ✓ and no duplicate is added.
  • Duplicates are checked in both directions, so the same pair does not appear twice.
  • Saved words survive browser restarts because they live in chrome.storage.local.
  • Nothing is written to your device at this point. Saving is entirely inside the extension.

Step 5 — Export to Markdown

Open the word bank from the popup or floating panel, or scroll to Words in Settings. Then:

  1. Choose a folder chip to narrow the list, or search for a word.
  2. Select specific words with the checkboxes if you only want some of them.
  3. Choose Markdown (.md) under File format.
  4. Optionally type a name under File name.
  5. Click Export selected, Export visible, or Export all.

The browser downloads the file to your default Downloads folder. The download starts only after you click an export button. If you want the extension to remove the words after a successful download, enable Delete exported words from the extension afterwards.

Step 6 — Open the file in your notes app

The download is a normal Markdown file. Move it into the folder or vault your notes app watches, then open it:

  • Obsidian: move the file into your vault and open it as a note.
  • Logseq: move it into your graph and open it as a page.
  • VS Code: open the file or the folder that contains it.
  • Any text editor: the file is plain UTF-8 Markdown.

What the exported file looks like

# Hassala — My words

| Word | Translation |
| --- | --- |
| hello | مرحبًا |
| كتاب | book |

Each row is just the word and its translation. Direction and dates are not stored or exported. Duplicate pairs do not receive a new row.

Tips that keep the workflow clean

  • Use one folder per course or project. Exporting a focused folder is easier to review than one giant list.
  • Export regularly. The extension is the working copy; the exported file is your portable backup.
  • Choose a meaningful file name. For example, arabic-course-a or programming-words.
  • Keep the optional delete checkbox off until you trust the export. It is safer to verify the downloaded file first.
  • Review in context. Open the export while watching a video or reading an article and test yourself on the rows.

Troubleshooting

“No words here yet”Save a word first, or switch the folder filter back to All words.
The download does not startCheck that your browser is not blocking downloads from the extension. Click the export button again and watch the Downloads toolbar.
“There are no words in this scope to export”The current folder or selection is empty. Choose another folder, clear the search, or select words first.
Some words are missingCheck the search field and the active folder chip. Export uses the visible list, not necessarily every saved word.
“Storage is full”Export your words, then delete the ones you no longer need or clear a whole folder.

FAQ

Do I need Obsidian to use Hassala?

No. Hassala exports standard Markdown. You can open it in Obsidian, Logseq, Typora, VS Code, or any text editor. Obsidian is optional.

Where does Hassala save words?

Saved words live in chrome.storage.local inside the extension, organised into folders. Hassala does not write to your filesystem automatically. When you export, the browser downloads a copy to your Downloads folder.

Do I need Python or a native host?

No. Hassala stores words with the browser's extension storage and exports through a normal browser download. There is no native host, Python requirement, or file-system permission.

Can I choose the export file name?

Yes. Type a name in the File name field before exporting. Hassala adds the correct extension and falls back to a dated name if the field is left empty.

Can I export to Anki or a spreadsheet?

Yes. Export CSV for spreadsheets or Anki import, JSON for scripts and backups, or Markdown for notes. There is no direct .apkg export yet.

Does exporting delete my words?

Only if you enable Delete exported words from the extension afterwards. Otherwise the words remain in the extension and can be exported again.
