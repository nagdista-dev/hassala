How to save translated words to Markdown

A repeatable Arabic ↔ English workflow for people who want a word bank they own — in Obsidian, Logseq, VS Code, or any text editor.

Updated November 3, 2026 6 min read Works with any Markdown editor

If you translate words while reading or watching videos, the translation usually disappears when you close the tab. This guide shows how to keep each word and translation in a local Markdown file with Hassala, then open that file in the notes app you already use.

What you need

  • Chrome, Brave, Edge, or Chromium on Linux, macOS, or Windows.
  • Hassala from GitHub Releases. The Chrome Web Store release is still being prepared.
  • Python 3 if you want saving to work (the tester package includes the native host).
  • A Markdown editor such as Obsidian, Logseq, Typora, or VS Code — optional, but useful.

Step 1 — Install Hassala

  1. Download hassala-2.0.4-testers.zip from Releases and extract it to a stable folder.
  2. Open chrome://extensions, brave://extensions, or edge://extensions.
  3. Enable Developer mode and click Load unpacked.
  4. Select the folder that contains manifest.json.
  5. From that same folder, install the native host:
    • Linux/macOS: bash native/install.sh
    • Windows: powershell -ExecutionPolicy Bypass -File native\install.ps1 -ExtensionId <id>
  6. Reload the extension from the extensions page.
Why a native host? Browsers do not allow extensions to write to arbitrary files. The host is a small local Python program that appends rows to your Markdown file. It runs locally, accepts messages only from Hassala, and writes only to .md files.

Step 2 — Choose your word bank file

Open Hassala Settings. The default path is: 

~/Documents/Hassala Words.md

If that file does not exist, Hassala creates it automatically on your first save. If you want a different file, choose any existing .md file with Choose file — for example, a note inside your Obsidian vault.

Custom paths must already exist. Hassala does not create new files in arbitrary locations.

Step 3 — Translate a word

There are three ways to open the translator:

  • Click the Hassala icon in the toolbar.
  • Click the floating button on any page.
  • Select text on a page and click Translate next to it.

Type an English or Arabic word. Hassala detects the direction and starts translating after a short pause, or immediately when you press Enter.

Step 4 — Save the word

When the translation looks right, click Add to Hassala. Hassala writes the word and translation to the file you chose, then clears the input for the next word.

  • If the pair already exists, you see Already in your word bank ✓ and no new row is added.
  • Duplicates are checked in both directions, so the same pair does not appear twice.
  • If saving fails, the word and translation stay in the input so nothing is lost.

Step 5 — Open the file in your notes app

The file is a normal Markdown table. Open it directly, or keep it in the folder your notes app already watches:

  • Obsidian: open the file in your vault, or use Open folder as vault if the file lives elsewhere.
  • Logseq: open the file as a page or import the folder.
  • VS Code: open the file or the folder that contains it.
  • Any text editor: the file is plain UTF-8 Markdown.

What the file looks like

| # | English | Arabic |
| --- | --- | --- |
| 1 | hello | مرحبًا |
| 2 | book | كتاب |

The # column is a counter. Duplicates do not receive a new number.

Tips that keep the workflow clean

  • Use one file per course or project. It is easier to review a focused list than one giant file.
  • Keep the table structure intact. Hassala appends rows; free-form notes are better in a separate file.
  • Back up or sync the file with the same tool you use for your notes. It is your file.
  • Review in context. Open the file while watching a video or reading an article and test yourself on the rows.

Troubleshooting

“Connection is not enabled”The native host is not registered, or the extension ID changed. Run the installer again and reload the extension.
“File not found”The custom path does not exist. Choose an existing .md file, or use the default file.
“Could not save”The file may not be writable. Check its permissions, then try again.
The input does not clearSaving failed, so Hassala kept your text. Check the connection status in Settings.

FAQ

Do I need Obsidian to use Hassala?

No. Hassala writes a standard Markdown file. You can open it in Obsidian, Logseq, Typora, VS Code, or any text editor. Obsidian is optional.

Where does Hassala save words?

By default, Hassala saves to ~/Documents/Hassala Words.md and creates that file on the first save if it does not exist. You can choose any existing .md file in Settings.

Can I use a file inside my Obsidian vault?

Yes. Choose any existing .md file in your vault from Hassala Settings. The file stays where it is; Hassala appends rows to it.

Does Hassala create new custom files?

Only the default file is created automatically. A custom path must already point to an existing .md file, so Hassala never creates files in arbitrary locations.

Can I export the word bank to Anki?

Not directly yet. CSV and Anki export are on the roadmap. Until then, you can convert the Markdown table with a script or copy rows into Anki manually.
