Guide

How to translate YouTube Arabic subtitles word by word

Watching a video in Arabic or English is a good place to meet new words. Keeping them is the hard part. This guide turns the captions into a lookup surface, then stores what you choose in a Markdown word bank.

Updated November 3, 2026 5 min read Chrome, Brave, Edge, Chromium

A caption that disappears in two seconds is a poor vocabulary notebook. Hassala keeps YouTube's own captions as the timing source, but shows an interactive copy in the same place. You can stop on a word, look it up without opening another tab, and save it to the same Markdown file you use for everything else.

What this guide is not. Hassala does not download subtitles, translate an entire video, or replace YouTube's caption settings. It is a word- and phrase-level lookup layer for captions that YouTube is already displaying.

What you need

  • Chrome, Brave, Edge, or Chromium on Linux, macOS, or Windows.
  • Hassala from GitHub Releases. The Chrome Web Store release is still being prepared.
  • A YouTube video with captions available — uploaded or auto-generated.
  • Python 3 if you want to save words; translation works without it.

Step 1 — Install Hassala

  1. Download hassala-2.0.4-testers.zip from Releases and extract it to a stable folder.
  2. Open chrome://extensions, brave://extensions, or edge://extensions.
  3. Enable Developer mode and click Load unpacked.
  4. Select the folder that contains manifest.json.
  5. To enable saving, install the native host from that folder:
    • Linux/macOS: bash native/install.sh
    • Windows: powershell -ExecutionPolicy Bypass -File native\install.ps1 -ExtensionId <id>
  6. Reload the extension. The full install steps are in the installation guide.

Step 2 — Turn on YouTube captions

Open any video and click CC in the player, or use the captions menu to pick a language. Hassala waits for YouTube to render captions, then replaces the visible caption layer with its own copy.

If you do not see interactive captions, first confirm that YouTube shows its normal captions with the extension disabled. If the video has no caption track, Hassala has nothing to work with.

Step 3 — Hover to pause, click a word

Move the mouse over the caption line. Playback pauses so the sentence does not slide away while you read. Move the pointer off the captions and the video resumes.

Click any word to send it to the floating translator. The panel opens with the translation, and the video stays paused until you press play. This is the difference between a quick glance and a real lookup.

  • Clicking a word does not navigate, seek, or toggle the player.
  • Only the word or phrase you choose is translated — never the whole page.
  • The panel can be dragged out of the way if it covers the captions.

Step 4 — Drag across a phrase

Some words only make sense together. Drag the mouse across several caption words and release. Hassala reads the highlighted text and translates the whole phrase instead of one token, then keeps the video paused.

This is useful for idioms, phrasal verbs, and short expressions such as get used to or على قدم وساق. A word-by-word translation of those is often worse than one translation of the phrase.

Step 5 — Save the word or phrase

In the floating panel, click the save button — labeled أضف للحصالة (Add to Hassala) in the Arabic-first interface. Hassala appends the source text and translation to the Markdown file you chose in Settings.

  • The default file is ~/Documents/Hassala Words.md.
  • You can point Settings at any existing .md file, such as a note in your Obsidian vault.
  • If the pair already exists, Hassala says so and does not add a duplicate row.
  • If saving fails, the word stays in the panel so you can fix the connection and try again.

What the file looks like

| # | English | Arabic |
| --- | --- | --- |
| 1 | get used to | يعتاد على |
| 2 | على قدم وساق | at full speed |

Phrases and single words share the same table. The # column is a counter, and duplicate pairs are skipped in both directions.

Tips for learning from video

  • Watch once for meaning, then rewatch for words. Stopping on every unknown word breaks the plot and the grammar.
  • Save phrases, not only isolated words. A phrase carries the preposition and the register with it.
  • Write down the context in your head. A word from a cooking video and the same word in a news report are not the same lesson.
  • Review the file the next day. Open it in Obsidian, Logseq, or any editor and read the rows out loud.
  • Use one file per series or topic. A focused list is easier to revisit than a giant dump.

Troubleshooting

Captions are not clickableCheck that YouTube is showing captions and that the video has a caption track. Reload the video after installing or updating Hassala.
The video will not resumeClicking a word keeps the video paused on purpose. Press play in the player, or click the video area away from the captions.
The panel covers the captionsDrag the panel by its header. Hassala remembers the position.
“Connection is not enabled”The native host is not registered, or the extension ID changed after reloading. Run the installer again with the current ID.
A saved phrase looks wrongAuto-generated captions can mishear words. Check the context before saving, and edit the row directly in the Markdown file if needed.

FAQ

Does Hassala translate the whole YouTube video?

No. Hassala makes the captions interactive: you choose a word or drag across a phrase, and only that text is translated. It is not a full-video or full-page translator.

Do I need captions to be enabled?

Yes. Hassala uses YouTube's own captions as the timing source, then displays an interactive copy in the same place. If the video has no captions or they are turned off, there is nothing to interact with.

Do auto-generated captions work?

Yes, if YouTube displays them. Auto-generated captions can contain recognition errors, so treat unusual words as uncertain and check the context.

Does clicking a word pause the video?

Yes. Hovering over the captions pauses playback while you read, and clicking a word keeps the video paused. Press play when you are ready to continue.

Can I save a phrase, not just one word?

Yes. Drag across several caption words before releasing the mouse. The floating panel translates the highlighted phrase, and the save button stores the phrase in the same Markdown table as single words.

Does subtitle translation require the native host?

No. Translating captions works without the native host. Saving to a Markdown file requires the local native host, because browsers cannot write to arbitrary files.
