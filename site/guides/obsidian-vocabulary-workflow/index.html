Guide

An Obsidian vocabulary workflow for Arabic learners

Use one ordinary note as an Arabic ↔ English word bank, save to it while you read, and review it without leaving your vault. No plugin and no second database.

Updated November 4, 2026 7 min read Obsidian + any Markdown editor

Obsidian is good at keeping notes you already wrote. Vocabulary is different: it arrives in small pieces, while you read or watch something, and it is easy to lose. This workflow connects the two. Hassala keeps each translated word in a private local word bank with folders; when you are ready, you export a Markdown note and bring it into your vault for search, links, and review.

What you need

  • Obsidian installed, with a vault you already use (or a new one).
  • Hassala from GitHub Releases. The Chrome Web Store release is still being prepared.
  • No Obsidian plugin, Python installation, or native host is required.

Step 1 — Create a folder in Hassala

Open Hassala Settings and find Save new words to. Create a folder for the course, language, or series you are studying: 

Arabic Course A
Arabic News
English Idioms
Programming

These folders live inside the extension. They let you export a focused list later instead of one giant file. A folder per series also makes the review habit easier to start.

Step 2 — Collect words while you read

Translate and save words from the toolbar popup, the floating panel, or YouTube captions. Each saved pair goes into the folder selected under Save new words to. Duplicate pairs are skipped in both directions, so saving the same word twice does not create noise.

Words are stored in chrome.storage.local. They survive browser restarts, but they are not written into your vault — or anywhere else on disk — while you collect them.

Step 3 — Export the folder as Markdown

  1. Open Words.
  2. Click the folder chip for the course or topic you want.
  3. Under File format, choose Markdown (.md).
  4. Under File name, type a clear name such as Arabic Course A.
  5. Click Export visible (or Export selected if you ticked specific rows).

The browser downloads the file to your default Downloads folder. The extension does not write into your vault directly, and the download only happens after you click an export button.

Why export instead of automatic writing? A browser extension should not have blanket access to your files. Keeping words in extension storage and exporting on demand is safer, easier to audit, and works the same on every operating system. You decide when a file is created and where it goes.

Step 4 — Move the file into your vault

Move the downloaded file from Downloads into your vault, for example: 

Arabic/Course A.md

Now it is an ordinary Obsidian note. You can open it, link it, tag it, and include it in your graph. If you prefer, set your browser to ask where to save each download so the file lands in the vault on the first try.

What the exported note looks like

# Hassala — My words

| Word | Translation |
| --- | --- |
| get used to | يعتاد على |
| على قدم وساق | at full speed |

The export is plain UTF-8 Markdown. Add your own headings, sources, and links above the table. Because a future export is a new snapshot, keep long-form notes in a separate note and link to the word bank, or merge changes manually when you refresh it.

Step 5 — Build a short review routine

A word bank only helps if you return to it. This routine takes about five minutes:

  1. Search the vault. Press Ctrl + Shift + F (Cmd on macOS) and search for a word you remember meeting.
  2. Open the note and read ten rows aloud. Reading aloud exposes words you recognize but cannot pronounce.
  3. Write one sentence with three of them. Put the sentence in your daily note, and link the word bank: [[Course A]]. The link makes the review note part of your graph instead of a dead end.
  4. Add context above the table when it matters. A source line or a short note about where you heard the word is enough.

Do not try to review the whole table every day. Ten rows is a habit; two hundred rows is a project you will postpone.

Step 6 — Re-export when the list changes

When you have added enough new words, export the folder again. You have two clean options:

  • Replace the old note with the newest export, so the vault note always mirrors the extension folder.
  • Keep dated snapshots such as Course A 2026-11.md, so you can compare progress over time.

The extension never edits or deletes notes in your vault. Replacing or merging files is a deliberate action you take in Obsidian or your file manager.

What this workflow does not do

  • No automatic vault writes. You export and move the file yourself.
  • No flashcards or scheduling. Hassala saves and deduplicates; it does not decide when you review.
  • No Dataview table. The rows are Markdown table cells, not frontmatter fields.
  • No direct Anki package. Export CSV for Anki import, or copy rows manually.
  • No page translation. Hassala translates words, selected text, and YouTube captions, not whole documents.

FAQ

Does Hassala have an Obsidian plugin?

No. Hassala exports a standard Markdown file. Obsidian reads that file like any other note, so no plugin or integration is required.

Does Hassala write directly into my vault?

No. Hassala stores words inside the extension and downloads an export only when you click Export. You move the downloaded file into your vault yourself.

Will exporting overwrite an existing note?

No. The browser saves a new download. If you want to update a note in your vault, replace it with the new export yourself or keep dated exports as snapshots.

Can I edit the exported note?

Yes. The exported file is ordinary Markdown that belongs to you. You can add headings, tags, links, and notes around the table. Remember that a future export is a new snapshot and will not include those edits unless you merge them.

Does this give me spaced repetition?

Not built in. Hassala saves and deduplicates words. For scheduled review, use an Obsidian plugin, Anki, or a manual routine. CSV export is available for Anki import.

Does it work with Obsidian Sync?

Yes, once the exported file is inside the vault. Obsidian Sync, Git, or any file sync tool can carry it. Hassala does not sync anything itself.
