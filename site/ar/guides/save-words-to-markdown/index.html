كيف تحفظ الكلمات المترجمة في Markdown

طريقة عملية متكررة للترجمة عربي ↔ إنجليزي وبناء بنك كلمات تملكه — جوه الإضافة بمجلدات، وتصدّره Markdown وقت ما تحب.

آخر تحديث: 4 نوفمبر 2026 قراءة 7 دقائق يعمل مع أي محرر Markdown

إذا كنت تترجم كلمات أثناء القراءة أو مشاهدة الفيديوهات، فغالبًا تختفي الترجمة بمجرد إغلاق التبويب. يوضح هذا الدليل كيف تحتفظ بكل كلمة وترجمتها في بنك كلمات خاص داخل حصالة، ثم تصدّر ملف Markdown وقت ما تحب وتفتحه في تطبيق الملاحظات الذي تستخدمه أصلًا.

ما تحتاجه

  • كروم أو بريف أو إيدج أو كروميوم على Linux أو macOS أو Windows.
  • حصالة من إصدارات GitHub. إصدار Chrome Web Store لسه قيد التحضير.
  • مفيش Python، ولا Native Host، ولا حساب، ولا صلاحية وصول للملفات.
  • محرر Markdown زي Obsidian أو Logseq أو Typora أو VS Code — اختياري، بس مفيد.

الخطوة 1 — ثبّت حصالة

  1. حمّل hassala-2.0.4-testers.zip من صفحة الإصدارات وفك الضغط في مجلد ثابت.
  2. افتح chrome://extensions أو brave://extensions أو edge://extensions.
  3. فعّل وضع المطور واضغط Load unpacked.
  4. اختر المجلد الذي يحتوي على manifest.json.
  5. ثبّت حصالة على شريط الأدوات لو عايز توصل لها بضغطة واحدة.
مفيش حاجة تانية تتثبت. الكلمات بتتخزن جوه الإضافة، مش في ملف على جهازك. مفيش Native Host، ولا اعتماد على Python، ولا كتابة تلقائية في الملفات.

الخطوة 2 — اعمل مجلد

افتح إعدادات حصالة، وهتلاقي Save new words to. اعمل مجلد للكلمات اللي بتجمعها، مثلًا English أو Arabic أو Programming.

المجلدات دي جوه الإضافة. هي أداة تنظيم، مش مجلدات على القرص الصلب. تقدر تغيّر اسمها، وتنقل الكلمات بينها، وتحذف مجلد من غير ما تحذف كلماته — الكلمات بترجع إلى General.

الخطوة 3 — ترجم كلمة

فيه ثلاث طرق لفتح المترجم:

  • اضغط أيقونة حصالة في شريط الأدوات.
  • اضغط الزر العائم على أي صفحة.
  • حدد نصًا في أي صفحة واضغط ترجم الذي يظهر بجواره.

اكتب كلمة إنجليزية أو عربية. تحدد حصالة الاتجاه وتبدأ الترجمة بعد توقف قصير، أو فورًا عند الضغط على Enter.

الخطوة 4 — احفظ الكلمة محليًا

عندما تكون الترجمة صحيحة، اضغط Add to Hassala. بيتحفظ زوج الكلمة والترجمة في المجلد المختار تحت Save new words to، وبعدها يتفرّغ المربع للكلمة التالية.

  • إذا كان الزوج موجودًا بالفعل، هتشوف موجودة بالفعل في حصالتك ✓ ولن يُضاف تكرار.
  • التكرار بيتفحص في الاتجاهين، فلن يظهر الزوج نفسه مرتين.
  • الكلمات المحفوظة بتفضل بعد إعادة تشغيل المتصفح لأنها في chrome.storage.local.
  • مفيش أي حاجة بتتكتب على جهازك في الخطوة دي. الحفظ كله جوه الإضافة.

الخطوة 5 — صدّر Markdown

افتح بنك الكلمات من البوب أو الصندوق العائم، أو انزل لقسم Words في الإعدادات. بعدها:

  1. اختار شريحة مجلد لتضييق القائمة، أو ابحث عن كلمة.
  2. حدد كلمات معينة بمربعات الاختيار لو عايز جزءًا منها بس.
  3. اختار Markdown (.md) تحت File format.
  4. لو حبيت، اكتب اسمًا تحت File name.
  5. اضغط Export selected أو Export visible أو Export all.

المتصفح بينزّل الملف في مجلد التنزيلات الافتراضي. التنزيل بيبدأ بس بعد ما تضغط زر التصدير. ولو عايز الإضافة تحذف الكلمات بعد تنزيل ناجح، فعّل احذف الكلمات المصدّرة من الإضافة بعد كده.

الخطوة 6 — افتح الملف في تطبيق الملاحظات

التنزيل ملف Markdown عادي. انقله للمجلد أو المكتبة اللي يراقبها تطبيق ملاحظاتك، وبعدين افتحه:

  • Obsidian: انقل الملف لمكتبتك وافتحه كملاحظة.
  • Logseq: انقله للـ graph وافتحه كصفحة.
  • VS Code: افتح الملف أو المجلد اللي فيه.
  • أي محرر نصوص: الملف Markdown عادي بترميز UTF-8.

شكل ملف التصدير

# Hassala — My words

| Word | Translation |
| --- | --- |
| hello | مرحبًا |
| كتاب | book |

كل صف فيه الكلمة وترجمتها بس. الاتجاه والتاريخ مش بيتخزنوا ومش بيتصدّروا. الأزواج المكررة مش بتاخد صف جديد.

نصائح تحافظ على نظافة الشغل

  • استخدم مجلدًا لكل دورة أو مشروع. تصدير مجلد مركز أسهل في المراجعة من قائمة ضخمة واحدة.
  • صدّر بانتظام. الإضافة هي نسخة العمل، والملف المصدّر هو نسختك المحمولة.
  • اختار اسم ملف واضح. مثلًا arabic-course-a أو programming-words.
  • سيب خيار Delete exported words from the extension afterwards مقفولًا لحد ما تثق في الملف. الأمان إنك تتأكد من التنزيل الأول.
  • راجع داخل السياق. افتح التصدير أثناء مشاهدة فيديو أو قراءة مقال واختبر نفسك في الصفوف.

حل المشاكل

«مفيش كلمات هنا لسه»احفظ كلمة الأول، أو رجّع فلتر المجلد إلى All words.
التنزيل مش بيبدأاتأكد إن المتصفح مش مانع تنزيلات الإضافة. اضغط زر التصدير تاني وراقب شريط التنزيلات.
«مفيش كلمات في النطاق ده للتصدير»المجلد الحالي أو التحديد فاضي. اختار مجلد تاني، أو امسح البحث، أو حدد كلمات الأول.
بعض الكلمات ناقصةراجع خانة البحث وشريحة المجلد النشطة. التصدير بيستخدم القائمة الظاهرة، مش بالضرورة كل الكلمات المحفوظة.
«التخزين ممتلئ»صدّر كلماتك، وبعدين احذف اللي مش محتاجه أو امسح مجلدًا كاملًا.

الأسئلة الشائعة

هل أحتاج إلى Obsidian لاستخدام حصالة؟

لا. حصالة بتصدّر Markdown عادي. تقدر تفتحه في Obsidian أو Logseq أو Typora أو VS Code أو أي محرر نصوص. Obsidian اختياري.

فين بتتخزن كلمات حصالة؟

الكلمات المحفوظة في chrome.storage.local جوه الإضافة، ومتنظمة في مجلدات. حصالة مش بتكتب على جهازك تلقائيًا. لما تصدّر، المتصفح بينزّل نسخة في مجلد التنزيلات.

هل أحتاج Python أو Native Host؟

لا. حصالة بتخزن الكلمات في تخزين الإضافة وبتصدّر من خلال تنزيل عادي في المتصفح. مفيش Native Host ولا Python ولا صلاحية وصول للملفات.

هل أقدر أختار اسم ملف التصدير؟

أيوه. اكتب اسم في خانة File name قبل التصدير. حصالة بتضيف الامتداد الصحيح، ولو الخانة فاضية بتستخدم اسم بتاريخ.

هل أقدر أصدّر لـ Anki أو جدول بيانات؟

أيوه. صدّر CSV لجداول البيانات أو استيراد Anki، أو JSON للسكربتات والنسخ الاحتياطي، أو Markdown للملاحظات. مفيش تصدير .apkg مباشر لسه.

هل التصدير بيمسح كلماتي؟

بس لو فعّلت احذف الكلمات المصدّرة من الإضافة بعد كده. غير كده الكلمات بتفضل في الإضافة وتقدر تصدّرها تاني.
