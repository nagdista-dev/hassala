دليل

كيف تحفظ الكلمات المترجمة في Markdown

طريقة عملية متكررة للترجمة عربي ↔ إنجليزي وبناء بنك كلمات تملكه — في Obsidian أو Logseq أو VS Code أو أي محرر نصوص.

آخر تحديث: 3 نوفمبر 2026 قراءة 6 دقائق يعمل مع أي محرر Markdown

إذا كنت تترجم كلمات أثناء القراءة أو مشاهدة الفيديوهات، فغالبًا تختفي الترجمة بمجرد إغلاق التبويب. يوضح هذا الدليل كيف تحتفظ بكل كلمة وترجمتها في ملف Markdown محلي باستخدام حصالة، ثم تفتح الملف في تطبيق الملاحظات الذي تستخدمه أصلًا.

ما تحتاجه

  • كروم أو بريف أو إيدج أو كروميوم على Linux أو macOS أو Windows.
  • حصالة من إصدارات GitHub. إصدار Chrome Web Store لسه قيد التحضير.
  • Python 3 إذا أردت تفعيل الحفظ (حزمة المختبرين تشمل Native Host).
  • محرر Markdown زي Obsidian أو Logseq أو Typora أو VS Code — اختياري، بس مفيد.

الخطوة 1 — ثبّت حصالة

  1. حمّل hassala-2.0.4-testers.zip من صفحة الإصدارات وفك الضغط في مجلد ثابت.
  2. افتح chrome://extensions أو brave://extensions أو edge://extensions.
  3. فعّل وضع المطور واضغط Load unpacked.
  4. اختر المجلد الذي يحتوي على manifest.json.
  5. من نفس المجلد، ثبّت الـ Native Host:
    • Linux/macOS: bash native/install.sh
    • Windows: powershell -ExecutionPolicy Bypass -File native\install.ps1 -ExtensionId <id>
  6. أعد تحميل الإضافة من صفحة الإضافات.
لماذا Native Host؟ لا تسمح المتصفحات للإضافات بالكتابة في أي ملف. الـ Host برنامج Python صغير محلي يضيف الصفوف إلى ملف Markdown الخاص بك. يعمل محليًا، ويقبل الرسائل من حصالة فقط، ويكتب في ملفات .md فقط.

الخطوة 2 — اختر ملف بنك الكلمات

افتح إعدادات حصالة. المسار الافتراضي هو:

~/Documents/Hassala Words.md

إذا لم يكن الملف موجودًا، تُنشئه حصالة تلقائيًا عند أول حفظ. وإذا أردت ملفًا مختلفًا، اختر أي ملف .md موجود من زر اختيار ملف — مثلًا ملاحظة داخل مكتبة Obsidian.

يجب أن تكون المسارات المخصصة موجودة بالفعل. لا تُنشئ حصالة ملفات جديدة في أماكن عشوائية.

الخطوة 3 — ترجم كلمة

فيه ثلاث طرق لفتح المترجم:

  • اضغط أيقونة حصالة في شريط الأدوات.
  • اضغط الزر العائم على أي صفحة.
  • حدد نصًا في أي صفحة واضغط ترجم الذي يظهر بجواره.

اكتب كلمة إنجليزية أو عربية. تحدد حصالة الاتجاه وتبدأ الترجمة بعد توقف قصير، أو فورًا عند الضغط على Enter.

الخطوة 4 — احفظ الكلمة

عندما تكون الترجمة صحيحة، اضغط أضف للحصالة. تكتب حصالة الكلمة والترجمة في الملف الذي اخترته، ثم تُفرّغ المربع للكلمة التالية.

  • إذا كان الزوج موجودًا بالفعل، سترى موجودة بالفعل في حصالتك ✓ ولن يُضاف صف جديد.
  • يعمل منع التكرار في الاتجاهين، فلن يظهر الزوج نفسه مرتين.
  • إذا فشل الحفظ، تبقى الكلمة والترجمة في المربع حتى لا يضيعا.

الخطوة 5 — افتح الملف في تطبيق الملاحظات

الملف عبارة عن جدول Markdown عادي. افتحه مباشرة، أو خليه في المجلد الذي يراقبه تطبيق الملاحظات:

  • Obsidian: افتح الملف داخل مكتبتك، أو استخدم Open folder as vault إذا كان الملف في مكان آخر.
  • Logseq: افتح الملف كصفحة أو استورد المجلد.
  • VS Code: افتح الملف أو المجلد الذي يحتويه.
  • أي محرر نصوص: الملف Markdown عادي بترميز UTF-8.

شكل الملف

| # | English | Arabic |
| --- | --- | --- |
| 1 | hello | مرحبًا |
| 2 | book | كتاب |

عمود # رقم تسلسلي. الكلمات المكررة لا تأخذ رقمًا جديدًا.

نصائح تحافظ على نظافة الشغل

  • استخدم ملفًا لكل دورة أو مشروع. مراجعة قائمة مركزة أسهل من ملف ضخم واحد.
  • حافظ على شكل الجدول. حصالة تضيف صفوفًا؛ والملاحظات الحرة مكانها الأفضل ملف منفصل.
  • اعمل نسخة احتياطية أو زامن الملف بنفس الأداة التي تستخدمها لملاحظاتك. الملف ملكك.
  • راجع داخل السياق. افتح الملف أثناء مشاهدة فيديو أو قراءة مقال واختبر نفسك في الصفوف.

حل المشاكل

«الاتصال غير مفعّل»الـ Native Host غير مسجَّل، أو تغيّر معرّف الإضافة. شغّل المثبّت مرة أخرى وأعد تحميل الإضافة.
«الملف غير موجود»المسار المخصص غير موجود. اختر ملف .md موجودًا، أو استخدم الملف الافتراضي.
«تعذّر الحفظ»قد يكون الملف غير قابل للكتابة. راجع صلاحياته وحاول مرة أخرى.
المربع لا يُفرَّغفشل الحفظ، فاحتفظت حصالة بالنص. راجع حالة الاتصال في الإعدادات.

الأسئلة الشائعة

هل أحتاج إلى Obsidian لاستخدام حصالة؟

لا. حصالة تكتب ملف Markdown عاديًا. يمكنك فتحه في Obsidian أو Logseq أو Typora أو VS Code أو أي محرر نصوص. Obsidian اختياري.

أين تحفظ حصالة الكلمات؟

افتراضيًا تحفظ حصالة في ~/Documents/Hassala Words.md وتنشئ الملف عند أول حفظ إذا لم يكن موجودًا. يمكنك اختيار أي ملف .md موجود من الإعدادات.

هل يمكن استخدام ملف داخل مكتبة Obsidian؟

نعم. اختر أي ملف .md موجود داخل مكتبتك من إعدادات حصالة. الملف يبقى في مكانه، وحصالة تضيف الصفوف إليه.

هل تنشئ حصالة ملفات مخصصة جديدة؟

الملف الافتراضي فقط هو الذي يُنشأ تلقائيًا. المسار المخصص يجب أن يشير إلى ملف .md موجود بالفعل، حتى لا تنشئ حصالة ملفات في أماكن عشوائية.

هل يمكن تصدير بنك الكلمات إلى Anki؟

ليس مباشرةً بعد. تصدير CSV وAnki على خارطة الطريق. حتى ذلك الحين يمكنك تحويل جدول Markdown بسكربت أو نسخ الصفوف يدويًا إلى Anki.
