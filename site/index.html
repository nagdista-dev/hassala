Features

A translator that remembers what you learned

Most translators help you in the moment and forget the word when you close the tab. Hassala keeps it — in a file you own, in the app you already use.

Instant translation

Type a word and the translation appears after a short pause, or press Enter. Arabic input switches direction automatically, and selected text can be translated from any page.

One-click saving

Add the word and translation to your Markdown file with one click. Hassala skips duplicates, so the same pair never appears twice.

Interactive YouTube subtitles

Hover a caption word to pause the video, click it to translate, or drag across a phrase to translate the whole phrase without leaving the player.

Your file, your app

Choose any existing .md file. Open it later in Obsidian, Logseq, Typora, VS Code, or a plain text editor. No export step and no lock-in.

Privacy by design

No accounts, no analytics, no ads, and no data selling. Settings and recent words stay in local browser storage, and saved words stay in your file.

Built for daily study

Pronunciation, copy buttons, a draggable panel, site blocking, and a floating button on every page — small details that keep the workflow fast.

How it works

Three steps, one growing word bank

Translation and saving stay in the same place, so nothing breaks your reading flow.

  1. Translate

    Click the toolbar icon, use the floating button, or select text on any page. Type in Arabic or English — the direction is detected automatically.

  2. Save

    Click Add to Hassala. The word and translation are appended to your Markdown file, duplicates are skipped, and the input clears for the next word.

  3. Review

    Open the same file in your Markdown app whenever you want. The words are already there — no export, no copy-paste, no separate database. See the step-by-step guide →

FAQ

Questions, answered plainly

Short answers to the things people ask before installing Hassala.

What is Hassala?

Hassala is a free, open-source Chrome extension for Arabic ↔ English translation and vocabulary saving. It translates words and phrases, writes each saved word and translation to a Markdown file on your device, and makes YouTube subtitles interactive. It does not require an account.

Is Hassala free?

Yes. Hassala is free and open source under the MIT license. There is no subscription, no account, and no paid tier.

Does Hassala work with Chrome, Brave, and Edge?

Yes. Hassala is a Manifest V3 extension that runs on Chrome, Brave, Edge, and Chromium on Linux, macOS, and Windows.

Can Hassala save words to Obsidian?

Yes. Hassala saves words to a standard Markdown file at a path you choose, so you can open that file in Obsidian, Logseq, Typora, VS Code, or any Markdown editor. The file does not have to live inside an Obsidian vault. Follow the step-by-step guide →

Do I need an account to use Hassala?

No. Hassala has no accounts, no sign-in, no analytics, and no tracking. Settings and recent words are stored locally in the browser.

Does Hassala work on YouTube?

Yes. When captions are enabled, Hassala replaces the native caption layer with interactive subtitles. Hover a word to pause the video, click a word to translate it, or drag across a phrase to translate the whole phrase.

Does saving words require a native host?

Yes. Browsers cannot write to arbitrary files, so Hassala uses a small local native messaging host to append rows to your Markdown file. The host is installed once, runs locally, and accepts messages only from Hassala. Translation, subtitles, and the floating panel work without it.

Is Hassala available on the Chrome Web Store?

Not yet. The Chrome Web Store release is being prepared. You can install Hassala today from the public GitHub releases page using the tester package and Load unpacked.

What languages does Hassala support?

Hassala translates between Arabic and English. The interface is Arabic-first with full right-to-left support, and the project documentation is available in English.

Privacy

No account. No tracking. No data selling.

Text is sent to translation providers only when you ask for a translation. Saved words go to your file, not to a server. Settings and recent words stay in local browser storage. Hassala has no backend, no analytics, and no ads.

Read the privacy policy →

Security at a glance

No remote code. Least-privilege permissions. The native host accepts only .md files and messages from Hassala. The page UI runs in a closed Shadow DOM. Vulnerabilities can be reported privately through GitHub Security Advisories.
