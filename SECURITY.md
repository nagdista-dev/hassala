# Security Policy — Hassala

## Supported versions

Security fixes are applied to the latest published release. Please update to the
latest version before reporting an issue.

## Reporting a vulnerability

- Use **Security → Report a vulnerability** in the
  [repository](https://github.com/nagdista-dev/hassala/security/advisories/new).
  This is the preferred path because it keeps the report private.
- If advisories are unavailable, open an issue titled `[security]` without
  sensitive details.
- **Do not disclose the details publicly** before a fix is available.
- Include the extension version, browser, operating system, reproduction steps,
  and impact.

## Full threat model

The complete security model, trust boundaries, permissions, and controls are in
