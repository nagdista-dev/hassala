# سياسة الأمان — حصالة

## الإصدارات المدعومة

بنصلح المشاكل الأمنية في آخر إصدار منشور. لو بتستخدم نسخة قديمة، جرّب تحدّث
الأول قبل ما تبلّغ.

## الإبلاغ عن ثغرة

- استخدم **Security → Report a vulnerability** في
  [الريبو](https://github.com/nagdista-dev/hassala/security/advisories/new).
  ده المسار المفضّل لأنه بيخلي البلاغ خاص.
- لو مش متاح، افتح Issue بعنوان يبدأ بـ `[security]` بدون نشر تفاصيل حساسة.
- **متنشرش التفاصيل علنًا** قبل ما يتم إصلاحها.
- اذكر: نسخة الإضافة، المتصفح، نظام التشغيل، خطوات إعادة المشكلة، والأثر.

## نموذج التهديد الكامل

الشرح الكامل للحدود الأمنية والصلاحيات والضوابط موجود في
[docs/SECURITY.md](docs/SECURITY.md).

# Security Policy — Hassala

## Supported versions

Security fixes are applied to the latest published release. Please update to the
latest version before reporting an issue.

## Reporting a vulnerability

Use **Security → Report a vulnerability** in the
[repository](https://github.com/nagdista-dev/hassala/security/advisories/new).
This keeps the report private. If advisories are unavailable, open an issue
titled `[security]` without sensitive details.

Please do not disclose the issue publicly before it is fixed. Include the
extension version, browser, operating system, reproduction steps, and impact.

The full threat model is in [docs/SECURITY.md](docs/SECURITY.md).
